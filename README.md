# Gravitas Sandbox Engine

2D-симулятор гравитации для системы тел. Интерфейс позволяет создавать и редактировать тела, управлять параметрами симуляции, наблюдать столкновения и слияния, а также перематывать историю.

## Возможности и реализация

- PyQt6-интерфейс на базе `QGraphicsScene` с масштабированием и перемещением по пространству.
- Физика N тел: гравитация, интегрирование движения, обнаружение столкновений через пространственную сетку и слияние тел.
- Дерево QuadTree и алгоритм Barnes–Hut для расчёта гравитации.
- Машина времени хранит снимки состояния и позволяет перемещаться по истории симуляции.
- При закрытии приложения отчёт о сессии сохраняется в `reports/`: длительность, сценарий, изменение числа тел, слияния и параметры симуляции.
- Сценарии хранятся в JSON. Pydantic проверяет данные на границе загрузки и сохранения; состояние симуляции представлено dataclass-моделями.
- Примеры сценариев находятся в `demo/`; тесты — в `tests/`.

## Требования

Python 3.10 или новее. Зависимости перечислены в `requirements.txt`.

## Запуск

Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Linux и macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Также можно запустить `run.bat` в Windows или `run.sh` в Linux/macOS; скрипты создают окружение, устанавливают зависимости и запускают приложение.

## Проверки и инструменты

```bash
python -m pytest
python benchmark/benchmark.py
ruff check .
mypy
```

Тесты производительности создаются для JSON-сценариев в `demo/`. Документация API собирается через Sphinx из файлов в `docs/source/`.
